# Markdown 导出遵循“显示工具与过程”开关

日期：2026-11-18

## 行为变化

原先“显示工具与过程”仅隐藏页面工具条目，Markdown 导出仍包含全部记录。现在详情和导出共用筛选规则：

- 勾选：保留完整记录和原有顺序。
- 未勾选：保留用户消息、正式回复和未记录阶段的旧版助手回复；过滤工具调用及输出、思考、计划、子代理活动等非消息条目，以及标记为 `commentary` / `analysis` 的助手过程消息。
- 兼容 `phase` 和旧版 `channel` 字段，保留 `final` / `final_answer` 正式回复。
- 导出仍先加载全部分页，然后读取当前开关状态生成 Markdown。桌面原生保存与浏览器下载使用同一份正文。

页面同步隐藏助手过程说明，取消勾选后继续加载的过程条目也会隐藏。

- 未勾选时保留 14 条（7 条用户消息、7 条最终回复），过滤其余 108 条（含 10 条过程说明、工具和思考记录）。勾选时导出全部 122 条。

- 补充验证旧版 `channel`、`final_answer`、无阶段回复、未知工具类型，以及导出补齐分页期间改变开关状态；均通过。页面 JavaScript 错误为 0。
- 现有 `python -m unittest discover -s tests -v` 共 23 项全部通过。
